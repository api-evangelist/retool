Retool is a low-code platform for building internal tools, dashboards, and admin panels quickly using pre-built UI components that connect to any database or API. Retool provides a management REST API for programmatically administering users, groups, apps, resources, permissions, and source control integrations. It supports enterprise features including SSO, SCIM 2.0 provisioning, self-hosting, and AI-powered app generation.

**Areas:** Admin Panel · Dashboards · Internal Tools · Low-Code · No-Code

### APIs (7)

- [Retool SCIM 2.0 API](https://apis.io/apis/retool/retool-scim-api/) — Retool implements a subset of the SCIM 2.0 API for automated user provisioning and group mapping through identity providers like Okta and Azure Active…
- [Retool Platform](https://apis.io/apis/retool/retool-platform/) — Retool's low-code platform provides a visual development environment with 100+ pre-built components, native connectors to 70+ data sources, AI-powered app…
- [Retool Apps API](https://apis.io/apis/retool/retool-apps-api/) — Create and manage Retool applications. Apps are the core visual building blocks created in the Retool editor.
- [Retool Folders API](https://apis.io/apis/retool/retool-folders-api/) — Organize apps, resources, and workflows into folders for better team organization.
- [Retool Groups API](https://apis.io/apis/retool/retool-groups-api/) — Manage groups and group membership. Groups control access to apps, resources, and workflows within the organization.
- [Retool Resources API](https://apis.io/apis/retool/retool-resources-api/) — Manage data source connections (databases, APIs, services) that power Retool queries.
- [Retool Users API](https://apis.io/apis/retool/retool-users-api/) — Create, read, update, and delete users within a Retool organization. Manage user roles (admin, standard, end-user) and activation status.
